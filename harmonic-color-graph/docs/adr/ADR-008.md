# ADR-008 — Licensing

**Status:** Accepted (roadmap v2)

**Context:** The corpus (Chordonomicon, Kantarelis et al., 2024)
license had not been checked before this revision. It determines
whether the product can ever be positioned commercially and what
attribution is legally required.

**Decision:** Chordonomicon is licensed CC BY-NC 4.0. The
project stays non-commercial (which also matches the Vercel
Hobby plan's terms) and displays attribution — "Chord data:
Chordonomicon (Kantarelis et al., 2024), CC BY-NC 4.0" with a
link — in the app footer, the evidence panel, the About page,
and the README. The pipeline manifest (`manifest.json`) records
the license per data source so future additional sources are
checked the same way before ingestion.

**Consequences:** No commercial use, paid tiers, or ads against
corpus-derived content without sourcing different data first;
every place a real song is referenced (evidence panel, examples)
must carry attribution, not just the homepage.

**Revisit trigger:** A future data source with a different
license is added (check and record it in the manifest before
ingesting), or there is a concrete plan to monetize — at which
point Chordonomicon-derived content must be separated out or
replaced.
